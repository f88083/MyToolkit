Markdown 表格生成器

右鍵點擊表格可進行編輯

基本編輯

  • 直接點擊表格任意欄位即可編輯內容
  • 編輯時會即時更新 Markdown 預覽
  • 按 Tab 可快速移動到下一格

Excel 表格快速匯入 隱藏功能

  • 在 Excel 或 Google Sheets 中複製表格
  • 在此頁面按 Ctrl+V 貼上
  • 系統會自動偵測並替換整個表格

右鍵選單功能 隱藏功能

  • 插入列/欄：在上下左右插入新的列或欄
  • 刪除列/欄：移除不需要的列或欄
  • 對齊方式：設定欄位靠左/置中/靠右
  • 提示：在任意表格欄位上按右鍵即可開啟選單

輸出與複製

  • 右側會即時顯示 Markdown 格式
  • 點擊「複製 Markdown」按鈕一鍵複製
  • 可直接貼到 GitHub、Notion、HackMD 等平台

快速上手技巧

Esc 關閉右鍵選單
Ctrl+V 貼上 Excel 表格
右鍵 開啟編輯選單
